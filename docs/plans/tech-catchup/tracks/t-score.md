# T-Score — スコアトラック

| 項目 | 内容 |
|------|------|
| 依存 | **C0 のみ**（フィクスチャ Item で開発） |
| 合流先 | M1（必須）、M2 |
| ゴール | 複数戦略を差し替えて `list[ScoredItem]`（降順）を返せる |

---

## 1. 目的

横断 Top 10 のための評価を、**戦略オブジェクトとして差し替え可能**にする。  
実ソース取得は不要。正規化ルールをここで固定する。

---

## 2. スコープ

### やること

- ソース内正規化ヘルパ（ランク or min-max）
- 戦略: `popularity` / `recency` / `hybrid`（デフォルト候補）
- metrics 欠落（GIGAZINE 等）の中立値扱い
- 戦略レジストリ
- 計算のユニットテスト

### やらないこと

- 実 HTTP 取得
- UI からの戦略選択画面（T-Web）
- パラメータ運用 UI（M3）

---

## 3. 正規化の約束

**禁止**: 生のいいね数をソース横断で直接比較すること。

手順案:

1. ソースごとにグループ化
2. ソース内で人気指標を 0〜1 に正規化
3. 指標が無いソースは中立値（例: 0.5）または recency のみで勝負

### 初期戦略

| name | 計算（初期案） |
|------|----------------|
| `popularity` | ソース内正規化人気のみ |
| `recency` | `published_at` からの時間減衰 |
| `hybrid` | `norm_popularity * recency_factor` |

半減期などは config キーを用意し、値の調整しやすさは M3 で深掘り。
