---

## 1. 候補メニュー

| ID | 内容 | 着手トリガー例 |
|----|------|----------------|
| M4-A | ホスティング | 外出先スマホから常用したくなった |
| M4-A' | Docker 化（開発 or 実行） | 環境差分が実害になった / CI・公開をコンテナに寄せたい（中では uv） |
| M4-B | 簡易認証 | URL を持つと第三者が触れうる |
| M4-C | GitHub Actions 定期実行 | 朝の自動生成が欲しくなった |
| M4-D | 無料枠 AI 要約 | 抜粋だけでは不足に感じた |
| M4-E | 有料 AI 要約 | 無料枠の品質/制限に不満 |
| M4-F | Google Drive 連携 | MD DL 運用が手間になった |

推奨検討順: **(A+B) → C → D → E → F**（状況で入れ替え可）。

---

## 2. 各候補の完了条件（要約）

| ID | 完了条件 |
|----|----------|
| A | スマホブラウザから一覧・取得ができる |
| A' | `docker compose` 等で再現起動でき、アプリはコンテナ内 uv で動く |
| B | 未認証では一覧も取得もできない |
| C | 手動/定期で結果がどこかに残る（Web 主トリガーは維持） |
| D | 要約オン/オフどちらでもパイプラインが落ちない。失敗時はルールベースへ |
| E | コスト上限超過時は要約スキップして継続 |
| F | 指定フォルダへ `.md` が置かれる。失敗時はローカル DL へ |

---

## 3. アーキテクチャ上の約束

- 要約は `excerpt` 上書きではなく別フィールド or 出力層
- Drive / LLM は Adapter 同様に隔離
- 認証は Web 層に閉じ、pipeline 純関数に持ち込まない
